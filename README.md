# Java Interview Dojo

A static site: no build step. Deploy the whole folder to Vercel (framework preset: "Other").

- `index.html` - the app
- `sw.js` + `manifest.webmanifest` + icons - "Add to Home Screen" and offline reading
- `vercel.json` - makes sure updates show up right away

Progress is saved in your browser (localStorage) on each device.
